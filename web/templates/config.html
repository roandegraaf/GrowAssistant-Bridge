What the sections do

General

Basic settings for the bridge itself.

  • log_level: how much it logs (DEBUG, INFO, WARNING, ERROR, CRITICAL)
  • log_file: where log files are stored
  • data_dir: where the bridge keeps its data
Connection

How the bridge talks to GrowAssistant.

  • url: the GrowAssistant address
  • batch_size: readings sent per batch
  • retry_max_attempts: how often a failed send is retried
  • poll_interval: seconds between command checks
Integrations

The hardware the bridge reads and switches:

  • gpio: Raspberry Pi pins
  • mqtt: MQTT broker connections
  • http: HTTP endpoints
  • serial: serial ports
